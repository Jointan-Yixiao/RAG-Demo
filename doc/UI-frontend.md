# 本地浏览器前端（web/）

2026-09-13。依据已确认的主界面、证据层和设置页三张设计稿实现。原生 HTML/CSS/JS，无构建、无依赖、无外部资源。

## 文件

- `web/index.html`：三个视图（主界面、证据层、设置）与三个弹窗（资料查看、大图、放弃修改确认）的静态结构。无内联脚本，符合 CSP `script-src 'self'`。
- `web/styles.css`：设计稿配色（#F7F8FA 侧栏、#E1E5E9 分隔线、#1D232A 文字等）、300px 侧栏；1180/1000/760px 三档响应式。760px 以下历史栏改为抽屉。
- `web/app.js`：路由、API 调用、轮询、安全 Markdown 渲染、证据层、设置表单。

## 路由（hash）

| 地址 | 视图 |
|---|---|
| `#/` | 历史加载后跳到最新一条；无历史时进入 `#/new` |
| `#/new` | 空白新问题 |
| `#/q/{id}` | 该问题的回答 |
| `#/evidence/{id}` | 该问题的证据层 |
| `#/settings` | 设置 |

## 行为约定

- 每条历史是独立问题，界面文案明确“不会参考之前的问答”。
- 输入框草稿保存在 sessionStorage（非凭据），切换视图、刷新后保留。Enter 发送，Shift+Enter 换行，输入法组字中的 Enter 不发送。
- 提交中禁用发送；`/api/health` 未就绪或不可达时禁用发送，并每 3 秒重新检查。
- 轮询：当前查看的问题处于 queued/running 时，每 1.8 秒请求详情；历史中有进行中条目时同步刷新历史。页面隐藏时暂停。
- 回答正文只渲染 `answer_markdown`，全部经 DOM 节点与 textContent 写入。支持标题、段落、列表（含嵌套）、代码块、行内代码、粗体/斜体、表格、引用、分隔线。只有绝对 http(s) 链接会成为 `<a target="_blank" rel="noopener noreferrer">`。
- 证据层只展示该回答详情中的 `evidence`，按 `document_id` 分组，显示真实 `citation_id`。图片只接受同源地址（与 CSP `img-src 'self'` 一致）。
- 设置：密钥输入框永远以空值加载；已配置时只改占位文字。留空保存不发送 `api_key`。测试连接发送当前未保存的值，超时 60 秒。服务端消息里若意外出现本次输入的密钥，显示前会被替换。离开有未保存修改的设置页时弹出确认；关闭或刷新页面时浏览器会提示。
- 资料弹窗只读：列表 + 原始 Markdown 纯文本。

## 已知限制与推迟事项（含触发条件）

1. **同次提交去重已实现**：前端生成提交标识，服务端按 `Idempotency-Key` 返回已有任务。同一问题的超时重试不会重复调用模型；标识在本标签的 sessionStorage 中保留到提交成功。清除站点存储后主动重新提问视为新任务。
2. **正文中残留引用标记不做前端过滤**：按接口约定由后端去掉 `[Sx]`。
   触发条件：主界面出现任何 `[S数字]` 字样时，先修后端；若后端无法保证，再在前端加过滤并写测试。
3. **Markdown 为子集实现**：不支持图片、HTML、脚注、任务列表、表格内多行单元格。
   触发条件：模型回答实际出现上述语法且影响阅读时补充。
4. **轮询没有退避**：服务长时间不可达时仍按 1.8 秒请求。
   触发条件：出现多个问题并发排队，或需要支持远程访问时，加入指数退避或改用 SSE。
5. **资料增删不在界面提供**：已发布后端不支持。
   触发条件：后端新增资料写入接口并完成重建索引流程时，再设计界面。
6. **实际接口已联调，浏览器点击验收待完成**：主代理已接入本机 Python 服务，跑通一道新的真实图文问题，并通过 HTTP 检查答案、引用、图片字节、原文、设置读写及连接测试。Chrome 自动浏览器当前返回 `ERR_BLOCKED_BY_CLIENT`；因此尚未声称浏览器点击链路通过。恢复浏览器访问后需补做实际页面点击验收，详见 `UI-本地工作台接入.md`。
