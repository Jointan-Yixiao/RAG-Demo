# 本地工作台接入与使用

## 桌面入口（2026-09-13 更新）

双击 `RAG-Workbench.exe` 或 `启动工作台.cmd` 打开图形启动器，再点击“打开工作台”进入网页。首次运行会自动创建桌面的“RAG 工作台”快捷图标；下载或克隆项目本身不会执行此操作。

新安装请先安装 Python 3.12（含 py 启动器）和 Node.js 24.x，然后点击“初始化环境”。程序会准备固定版本的依赖、GME、BGE 和资料索引，不调用付费 API。已有完整环境会复用。网页“设置”里填写自己的 API 密钥。

退出时点击“停止服务”，或使用 `停止工作台.cmd`。关闭网页和启动器不等于停止后台服务；正在生成回答时不能停止。图标缺失时点击“修复桌面图标”。

详细构建方式及已知边界见 [启动器说明](启动器实现说明.md)。


2026-09-13。已确认的主界面、证据层、设置页已实现为本机网页，并接入现有 RAG 运行流程。

## 使用

双击桌面的 **RAG 工作台** 图标，在启动器中点击 **打开工作台**，浏览器打开 `http://127.0.0.1:8765`。如果服务已经启动则直接复用；结束使用后在启动器点击 **停止服务**。

1. 主界面输入问题后发送，页面显示理解问题、检索资料、筛选证据、生成回答等真实阶段。每个问题独立处理，不自动引用之前的问答。
2. 回答完成后保存在左侧历史，刷新网页或重启服务仍可读取。
3. 点击“引用来源 / 证据层”，查看这份回答实际引用的正文和图表。切换条目、查看大图、打开在线来源、本地原文均已实现对应接口和前端处理。
4. 设置页可修改 OpenAI 兼容接口地址、模型和密钥，保存回答语言与详细程度。设置在新问题提交时取快照；不改变此前的答案。
5. “查看资料”列出已入库的 10 份资料。资料增删与重新入库流程不在这一版网页中。

## 模型和运行边界

默认沿用项目现有 DeepSeek 配置和凭据。密钥字段显示“已配置”时留空保存即可；输入新密钥会以当前 Windows 用户的 DPAPI 加密后保存在本机。密钥不会返回网页，也不保存在浏览器存储。更换接口地址时必须填写该接口的密钥，避免误用旧凭据。

浏览历史、打开证据和保存设置不调用模型。提交问题会调用真实模型；“测试连接”会发起一条最多 32 个输出 token 的小请求，服务商可能收费。不进行自动整题重试；同次提交带去重标识，网络超时后重试会返回已经创建的任务。

检索和重排使用原有默认参数：混合检索、K=10、词法补充上限 20、BGE v2 m3、回答复核开启。GPU 工作按队列串行执行，最多等待 8 个任务。服务重启会将未完成任务标为中断，不自动重新调用付费模型。

当前以完整阶段进度展示等待过程，尚未逐 token 流式输出。其他 OpenAI 兼容模型可以配置，但必须支持现有流程所需的 JSON 输出与图片输入；仅实测过当前 DeepSeek 配置。

本机服务只监听 `127.0.0.1`，不对局域网开放。它拒绝跨站请求及非本机 Host；只开放网页文件、所选证据图片与目录内原文，不是整个项目的文件服务器。

## 文件与数据

| 位置 | 用途 |
|---|---|
| `web/` | 实际 HTML / CSS / JavaScript 前端，无构建步骤和 CDN |
| `scripts/_rag_web.py` | 本机 HTTP 服务、设置、任务队列、历史与证据适配 |
| `scripts/_rag_web_worker.py` | 独立进程调用原有端到端入口，附加阶段通知 |
| `scripts/_launch_workbench.py` | 启动、复用和停止本机服务 |
| `data/ui/settings.json` | 偏好设置与可选的加密密钥 |
| `data/ui/jobs/<id>/` | 问题、设置快照、原始运行回执和网页结果 |
| `data/ui/acceptance/` | 本次接口验收回执 |

`data/ui/` 已加入本地忽略规则。原有 RAG 核心脚本和历史验收数据未修改。当前目录的部分旧文件是硬链接；修改 `.gitignore` 时已先解除该文件的硬链接，避免同时影响其他发布副本。

命令行启动（调试时保留窗口）：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts\_rag_web.py
```

若端口占用可传 `--port 8766`。默认先使用当前项目的 `data/runtime/index`（若存在），否则使用已验证的分层索引；也可以显式传入 `--index-dir`。重排模型目录可以通过既有 `RAG_BGE_MODEL_DIR` 设置。
